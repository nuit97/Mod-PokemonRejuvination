# Crédits et distribution

**Nuit** a défini le concept, les règles et les arbitrages de ce mod. Le Mode Nuit est une extension communautaire indépendante.

**Janichroma et l’équipe Rejuvenation** développent le jeu original, son histoire, ses combats, son moteur adapté et ses ressources. Le fichier `Modding.txt` de la version 14.0.28 documente l’ajout de scripts dans `patch/Mods/`. Le fichier `ReadMe_Credits.txt` précise les conditions de réemploi des ressources, notamment pour les musiques originales et les personnages. Le ZIP distribué contient exclusivement les scripts spécifiques au Mode Nuit. [Site du jeu](https://rejuvenationgame.com/download)

**bss3m et les contributeurs de RejuvFR** proposent la traduction française facultative. Elle se télécharge auprès du projet d’origine. [RejuvFR](https://github.com/bss3m/RejuvFR)

Pokémon et les œuvres d’origine appartiennent à leurs titulaires respectifs. La notice de distribution de ce dépôt porte sur les contributions originales du Mode Nuit. [Licence](../LICENSE)
